### Absctrac class vs Interfaz
- Abstract class: Cuando varias clases comparten estado y comportamiento.
- Interfaz: Cuando diferentes clases necesitan compartir una capacidad o contrato, aunque no tengan relación entre sí.
### Class explosion
- A class explosion occurs when a software system has a large number of classes, often beyond what was originally anticipated or well-structured.
- If we have a abstract class and then we notice that it has a several uses a long the proyect, we are inside an anti-pattern.
